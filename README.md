# Halo Vorlagen – Updates

Hier liegen die fertigen, von Mozilla signierten Versionen der Browser-Erweiterung **Halo Vorlagen**
(HaloITSM-Helfer) und die Update-Datei, über die sich die Erweiterung selbst aktualisiert.
Der Quelltext liegt in einem privaten Repository.

## Firefox

**Installieren:** die neueste `.xpi` aus [`firefox/`](firefox/) herunterladen und in Firefox ziehen
(oder `about:addons` → Zahnrad → „Add-on aus Datei installieren …“).

Danach aktualisiert Firefox die Erweiterung selbst: Es prüft etwa einmal am Tag
[`firefox/updates.json`](https://pacokeks.github.io/halo-vorlagen-updates/firefox/updates.json)
und installiert neue Versionen automatisch. Sofort prüfen: `about:addons` → Zahnrad →
„Nach Updates suchen“.

Auto-Update gibt es ab der ersten Version, die von hier installiert wurde (ältere Versionen kennen
diese Adresse nicht).

## Chrome

Folgt, sobald die Erweiterung im Chrome Web Store ist.
